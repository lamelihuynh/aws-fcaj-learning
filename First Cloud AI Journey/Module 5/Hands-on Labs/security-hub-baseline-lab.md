# Security Hub Baseline Lab

## Goal

Review how AWS Security Hub presents findings and helps measure baseline security posture.

## Lab Flow

1. Confirm AWS Config prerequisites where required.
2. Enable Security Hub in the target Region.
3. Select relevant security standards.
4. Review generated findings and severity levels.
5. Pick one finding and trace the affected resource.
6. Record how the finding would be remediated.
7. Disable or clean up lab resources when finished.

## Validation

The lab is complete when findings are visible, one finding is explained and cleanup decisions are documented.
