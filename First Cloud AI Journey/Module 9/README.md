# Module 09 - Kiến trúc DevSecOps, workshop và báo cáo cuối kỳ

## Phạm vi module

Phần này gom phần tổng hợp cuối: biến các dịch vụ đã học thành kiến trúc DevSecOps có security gate, artifact report, observability, cost cleanup và tài liệu song ngữ có thể trình bày.

## File trong thư mục

- File `module-...md`: lưu phần lý thuyết, thuật ngữ và ý chính.
- Thư mục `Hands-on Labs/`: lưu luồng thực hành, kiểm chứng và ghi chú cleanup.
