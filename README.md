# AWS FCAJ Learning - Personal Evidence Repository

This repository is my personal evidence repository for the AWS First Cloud AI Journey internship report. It contains rewritten study notes, lab summaries and weekly worklog evidence that support the Hugo report in `aws-fcaj-report`.

The structure uses descriptive slugs, module-level indexes, and weekly evidence pages so it reads as my own study portfolio rather than a raw collection of workshop files.

## Repository Structure

```text
aws-fcaj-learning/
├── First Cloud AI Journey/
│   ├── README.md
│   ├── Module 1/ ... Module 6/
│   └── each module contains notes, README and practice evidence
├── Worklogs/
│   └── 01-...md to 09-...md
└── Blog-Proofs/
```
